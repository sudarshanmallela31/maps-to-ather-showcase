# Maps to Ather Bridge 🛵

Independent Google Maps-to-Ather navigation companion by **Sudarshan Mallela**.

**[Live website](https://maps-to-ather-bridge-skcomputers296-5546.vercel.app)** · **Source code: private/not publicly released.**

## Problem
Some Android navigation apps do not accept all Google Maps shared URL formats. This app converts supported Google Maps links into coordinates and offers Android handoff and copy/share alternatives.

## Features
- Google Maps URL and short-link conversion
- Optional interactive map preview
- Local recent destinations and favorites
- Installable PWA with premium midnight black, cobalt blue and acid lime design
- Validation and bounded server-side redirect handling

## Tech and engineering
HTML, CSS, JavaScript, Node.js serverless functions, Progressive Web App technologies, Vercel. Engineering work includes coordinate extraction, safe redirect processing, fast PWA startup and user-friendly errors.

## Limitations
Independent project, not affiliated with Ather or Google. Converting a location does **not** guarantee scooter navigation handoff. Frontend files served by the live demo can be inspected in a browser, even though the original GitHub source repository is private.
